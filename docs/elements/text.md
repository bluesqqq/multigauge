# Text

![Text preview](../../assets/placeholder.jpg)

The text element draws a single line or block of text inside its layout bounds.

## Header

[`core/include/multigauge/gauge/elements/primitives/TextElement.h`](../../core/include/multigauge/gauge/elements/primitives/TextElement.h)

## Properties

### `text`
The string content rendered by the element.

### `paint`
Text color and stroke styling.

### `ellipses`
Controls whether overflowing text is truncated with an ellipsis.

### `hyphens`
Controls whether the text may hyphenate when it wraps.
