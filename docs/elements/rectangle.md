# Rectangle

![Rectangle preview](../../assets/placeholder.jpg)

The rectangle element draws a filled or stroked rectangular shape inside its layout bounds.

## Header

[`include/multigauge/gauge/elements/primitives/RectangleElement.h`](../../include/multigauge/gauge/elements/primitives/RectangleElement.h)

## Properties

### `paint`
Controls the fill and stroke styling used to draw the rectangle.

### `radius`
Rounds the rectangle corners when greater than zero.
