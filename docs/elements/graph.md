# Graph

![Graph preview](../../assets/placeholder.jpg)

The graph element draws a time-series style value chart.

## Header

[`include/multigauge/gauge/elements/Graph.h`](../../include/multigauge/gauge/elements/Graph.h)

## Properties

### `seconds`
Time window shown across the graph.

### `bgColor`
Background color behind the graph.

### `secondsColor`
Color used for the time axis labels or markers.

### `graphColor`
Color used for the graph line or filled trace.

### `borderColor`
Border color drawn around the element bounds.

### `value`
Source value displayed by the graph.
