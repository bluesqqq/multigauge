# Horizon

![Horizon preview](../../assets/placeholder.jpg)

The horizon element renders a synthetic horizon-style background and grid.

## Header

[`include/multigauge/gauge/elements/Horizon.h`](../../include/multigauge/gauge/elements/Horizon.h)

## Properties

### `bgColor`
Base background color behind the horizon.

### `groundColor`
Color used for the ground region.

### `horizonColor`
Color used for the horizon line.

### `borderColor`
Border color drawn around the element bounds.
