# Circular Needle

![Circular needle preview](../../assets/placeholder.jpg)

The circular needle element draws a needle against a circular value range.

## Header

[`include/multigauge/gauge/elements/circular/CircularNeedle.h`](../../include/multigauge/gauge/elements/circular/CircularNeedle.h)

## Properties

### `paint`
Controls the fill and stroke styling used to draw the needle.

### `radius`
Radius used to position the needle around the circular bounds.
