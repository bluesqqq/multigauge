# Circular Scale

![Circular scale preview](../../assets/placeholder.jpg)

The circular scale element draws a tick scale around a circular range.

## Header

[`include/multigauge/gauge/elements/circular/CircularScale.h`](../../include/multigauge/gauge/elements/circular/CircularScale.h)

## Properties

### `ticks`
Tick configuration used to render the scale marks.

### `radius`
Radius used to place the scale around the circular bounds.

Tick data lives under [`include/multigauge/gauge/ticks`](../../include/multigauge/gauge/ticks).
